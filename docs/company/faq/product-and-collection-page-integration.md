# Product and Collection Page Integration

*Advance FAQ*

## Does this App work with the BUY NOW button on the product page?

Yes, "BUY NOW" button is supported.

## Can I showcase the discounted price next to the original price instead of using a pricing grid?

Yes, you have the option to showcase the discounted price for a single quantity and
eliminate the price grid.

## Is this app compatible with Payment Gateways?

Yes, this app is compatible with other Payment Gateways.

## How many collections can I add to a single offer?

You can add up to 10 collections in a single offer. If you need to apply rules to more
than 10 collections, you will need to create a separate offer.
