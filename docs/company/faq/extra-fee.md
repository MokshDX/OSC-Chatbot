# Extra Fee

*Advance FAQ*

## How do I charge a packaging fee on specific products only?

Set the rule's "Applies To" field to Specific Products (or a collection) and add a fixed
fee. Only those products will trigger the packaging charge — other items in the cart are
ignored.

## How do I add a flat handling fee to every order?

Create a rule that applies to All Products with a single slab and a fixed fee. The fee
will be added to every cart that meets the rule's conditions.

## Can I run more than one extra fee at the same time?

Yes. You can create unlimited rules. They run side-by-side and you control whether they
stack or whether only one wins (see "Priority & Stacking" below).

## Do I need to write any code to set up an extra fee?

No. You create rules from the app dashboard using simple conditions such as cart value,
quantity, customer tag, or selected products. The fee is added on the storefront
automatically.

## What is the Extra Fee feature?

Extra Fee lets you add one or more surcharges to a customer's order based on rules you
define — for example, a handling fee, a packaging charge, a COD fee, or a B2B service fee.
Fees appear automatically in the cart and at checkout.
